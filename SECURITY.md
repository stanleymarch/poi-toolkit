# Security Policy

## Supported versions

Security fixes are made on the current `main` branch. This project has not yet
published a separately supported release line.

## Reporting a vulnerability

Please **do not** open a public issue for a suspected vulnerability. Use the
repository's [private vulnerability reporting](https://github.com/stanleymarch/poi-toolkit/security/advisories/new)
when it is available. If private reporting is unavailable, contact
[@stanleymarch](https://github.com/stanleymarch) privately through GitHub and
include `poi-toolkit security report` in the message subject.

Provide a clear description, affected revision, reproduction steps, impact,
and any proof of concept. Do not access, alter, or exfiltrate data that you do
not own while researching a report.

We aim to acknowledge reports within seven days, provide status updates as the
issue is investigated, and coordinate a fix and disclosure timeline with the
reporter. Please allow time for a fix before public disclosure.

## Scope

Report vulnerabilities in this repository and its published automation. Source
data quality problems, upstream service availability, and consumer-side
Nearventure importer or database issues should be reported to their respective
owners unless they are caused by code in this repository.
